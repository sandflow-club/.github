# Sandflow.club

Sandflow.club is a community inspired by the tildeverse — a public-access Unix system for exploration, creation, and sharing.  
It is a computer meant for people, not platforms.

---

## About

Sandflow.club runs on a Linux server.  
It welcomes anyone who appreciates free and open-source software, minimalism, the suckless philosophy, retrocomputing, and peer education.  
Our purpose is to keep alive the spirit of shared computing — where curiosity, simplicity, and respect come first.

We believe small is beautiful, sharing is strength, and technology should stay humane.

To keep this space clean and friendly:

- Do not host illegal content.  
- Do not use this server for commercial purposes.  
- Respect other users as you would want to be respected.

---

## Join

If you enjoy learning, building, and exploring alongside others who value simplicity and openness, you’ll fit right in.  
Each member receives a shell account, some disk space, and the freedom to create.
